Project Description:
The Transaction Traffic is a simple and easy-to-use budget tracking application that helps you manage your finances. It allows you to track your transactions, set an initial balance, convert currencies, and perform all tasks without needing to sign up for an account.

Features:
-Real-Time Balance Updates: The balance updates automatically as you add or remove transactions.
-Transaction Management: You can add, edit, and delete transactions.
-Currency Converter: Convert amounts between USD, EUR, and GBP using predefined exchange rates.
-Search Functionality: Easily search for transactions by category, description, or date.
-User-Friendly Interface: Clean, simple, and intuitive design.
-No Account Needed: No sign-ups, just open and use immediately.

Technology Stack:
-HTML: Structure and layout of the app.
-CSS: Styling for responsive design.
-JavaScript: Handles functionality like real-time balance updates, event handling, and currency conversion.

How to Use:
-Open the BudgetTracker.html: Open the BudgetTracker.html file in your browser to start using the app.
-Set Initial Balance: Enter the starting balance and click "Set Initial Balance."
-Add Transactions: Fill in the details and click "Add Transaction."
-Edit or Delete Transactions: Use the Edit and Delete buttons in the transaction history to modify or remove entries.
-View and Search Transactions: Filter transactions by category or description using the search bar.
-Convert Currency: Enter an amount and convert between different currencies (USD, EUR, GBP).
